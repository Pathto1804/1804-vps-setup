# 业务与边界

## 这是什么

给个人在国内云算力平台（GPU 云主机或容器实例）上从零部署 ComfyUI 的单入口 TUI。目标状态一句话：**一条命令得到能出图的 ComfyUI，默认公网 8188 可访问，重跑只补未达标项**。

使用者画像：能 SSH、知道 Snapshot、接受公网暴露风险的个人用户；不面向批量自动化或多租户。

## 成功标准

1. 标准部署完成后 `curl 127.0.0.1:8188` 返回页面，`torch.cuda.is_available()` 为 True（GPU 模式）。
2. 终检打印 `http://<公网IP>:8188`、云安全组放行提示与 SSH 隧道后备命令。
3. 重跑标准部署不重复下载、不重写已达标的 unit/start.d、不重启未变化的服务。
4. 所有写操作前备份到 `/root/vps-init-backups/`；没有项目私有状态文件。

## 支持矩阵

- **一等**：Ubuntu 22.04 / 24.04（x86_64）。
- **兼容未逐版本验证**：Debian 12 / 13，仅 NVIDIA 官方源路径。
- **硬依赖**：`nvidia-smi` CUDA Version >= 13.0（驱动 >=580）；GPU 模式不支持 `cu126` 回退。
- **无 GPU**：CPU 测试模式，装 PyTorch CPU 索引，启动加 `--cpu`。

## 明确不做

- 不合并进 `00-tui.sh`；不负责 SSH/UFW/fail2ban/Swap/BBR 的安全基线。
- 不装 Docker，不做 Nginx/HTTPS/认证代理。
- 不自动下载模型；不托管模型。
- 不支持非 root、多用户、ARM64。
- 不自动启用 UFW；不自动重启服务器。
- 不自动回滚 ComfyUI 代码；更新失败只打印回滚命令。
- 不收集任何 API key 或账号凭据。

## 默认访问的风险（有意选择）

默认 `--listen 0.0.0.0:8188` 是用户明确选择。ComfyUI 无鉴权，任何能访问该端口的人都能使用画布和 Manager。脚本在标准部署开始时打印一次风险摘要；菜单 7 保留切换为仅回环 + SSH 隧道的后备路径。
