# 术语表

本仓库的领域语言。措辞以本页为准；其他文档与 `.omp/AGENTS.md` 使用这些词时不再另行定义。

**自包含脚本**
单文件即可被 raw 拉取并独立执行的脚本；不 `source` 仓库内其他文件，公共函数内联于每个脚本且内容完全一致。
_Avoid_: 模块化脚本、入口脚本、子模块

**步骤号（前缀号）**
README 步骤与脚本文件的映射规则：文件名前缀是该脚本覆盖的**起始**步骤号，一个脚本可以覆盖多个连续步骤号（README 写作区间，如 `01` 覆盖步骤 1–2）。步骤号一经确定不再重排；手动步骤无脚本（3/10/11），跳号是有意的。
_Avoid_: 脚本编号、章节号

**编排器**
被本项目明确拒绝的形态：由一个总控脚本（如 `init.sh run`）按状态调度其余脚本。本项目中编排由人完成（README 提供命令与顺序）。见 [ADR-0001](../adr/0001-no-orchestrator.md)。
_Avoid_: runner、入口脚本

**闸门**
脚本内强制的人工确认点（y/N 交互）。对应三条铁律的生死关口；答 N 即退出（退出码 1），不存在"跳过"。
_Avoid_: 确认弹窗、跳过选项

**前置自检**
脚本启动时对系统真实状态的检查（ufw 是否放行端口、用户是否存在）。不满足即拒绝执行。检查的是当下系统状态，不是脚本自己的历史记录。个别检查落在写入动作之前而非脚本启动时（`07-fail2ban.sh` 的 jail 端口校验、`05-ufw-ssh.sh` 启用前的放行确认），同样是不满足即拒绝该动作。
_Avoid_: 状态检查文件、进度记录

**配置文件**（`/root/.vps-init.conf`）
跨脚本参数在目标机器上的本地存储（端口、用户名、公钥等）。脚本读不到对应键则交互询问并写盘；600 权限、root 属主，永不进入仓库。
_Avoid_: init.conf、设置向导

**维护菜单**
脚本的常驻交互循环（`04-user.sh` / `05-ufw-ssh.sh` / `07-fail2ban.sh` / `08-swap.sh`）：显示当前状态行 + 编号操作项，一次只做一件事。**首次运行不自动执行任何写操作**——初始化/加固/安装全部由用户从菜单选择。菜单只呈现动作，不放宽闸门与前置自检。
_Avoid_: 向导、配置中心、TUI 框架

**交互契约**
三份菜单脚本（`04`/`05`/`07`）共用的输入语义，由公共交互原语（`ask_menu`/`ui_item`/`ui_kv`/`ui_sep`/`ui_rule`/`ui_quit`/`ui_abort`）实现，`08-swap.sh` 以自有 helper 遵循同一语义。规则：`0` = 退出（主菜单）/ 返回（子菜单），空回车等价于 `0`；非法输入原地重问、不重绘整页；`Ctrl-C` 打印"可能只改了一半、重跑收敛"的说明后以退出码 130 退出。菜单编号与 `README.md`/`features.md` 的引用一一对应，改编号必须同批改文档。
_Avoid_: 菜单框架、UI 库

**输入中断**
交互提示处读到 EOF（`Ctrl-D` 或输入流结束）时的终止语义：脚本立即以退出码 1 退出，绝不把空值写入 conf 或系统配置。实现依赖 `shopt -s inherit_errexit`——bash 默认不把 errexit 继承进命令替换，不开启则 `$(ask_input ...)` 里的 `die` 只终止子 shell，空值会被照常写盘。
_Avoid_: 输入错误、参数非法

**备份目录**（`/root/vps-init-backups/<时间戳>/`）
脚本修改任何系统配置文件前自动留存的副本。恢复靠人工从副本还原，脚本不做自动回滚（例外：`05-ufw-ssh.sh` 菜单 10 的「从备份恢复」会先 `sshd -t` 校验，失败即退回恢复前的版本）。
_Avoid_: 快照、版本库

**终检报告**（`/root/vps-init-report.md`）
`12-verify.sh` 产出的绿/红检查报告，兼作初始化参数的归档记录。有红项时 `12-verify.sh` 以退出码 1 结束。

**fail closed**
校验条件无法确认时选择**拒绝写入/拒绝执行**，而不是用默认值继续。应用点：`07-fail2ban.sh` 读不到 sshd 端口或端口不一致时拒绝写 `jail.local`。相对地，只读检查中的不确定用黄灯（"未知"）表达，不判红也不假装通过。
_Avoid_: 兜底、降级放行

**原始执行（raw 执行）**
主交付形态：`sudo -i` 后在 root 会话里 `bash <(curl -fsSL <raw URL>)`，脚本不进磁盘、不预装 git。与「本地副本执行」只有脚本来源不同，步骤与闸门完全一致。
_Avoid_: 在线版、云执行

**本地副本执行**
可选形态：`git clone` 仓库到 VPS 后 `bash NN-xxx.sh`。用于整套固定版本、执行前审阅、反复进维护菜单。脚本自包含，因此执行目录不影响行为。
_Avoid_: Git 版、离线版（本地副本仍需要网络装包）

**CodeWiki**
`docs/codewiki/` 下的维护者知识库：业务边界、架构、功能清单、开发流程、术语。回答"为什么"与"怎么改"；`README.md` 回答"怎么用"。
_Avoid_: 文档站、知识库（泛称）
