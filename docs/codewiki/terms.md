# 术语表

本仓库的领域语言。措辞以本页为准；其他文档与 `AGENTS.md` 使用这些词时不再另行定义。

**ComfyUI 部署脚本**（`comfyui-tui.sh`）
与基础初始化脚本并列的第二入口，单文件自包含，负责 GPU/CPU 环境、Miniforge、ComfyUI、PyTorch、模型目录、访问方式与自启；不负责 SSH/UFW 安全基线。专属术语见 [`comfyui-docs/codewiki/terms.md`](../../comfyui-docs/codewiki/terms.md)。
_Avoid_: 原脚本、新脚本、增强版

**单入口脚本**（`00-tui.sh`）
基础初始化入口脚本，单文件即可被 raw 拉取并独立运行：不 `source` 仓库内其他文件，所需函数全部内联。所有基础功能（更新、用户、UFW/SSH、fail2ban、Swap、BBR、终检）都在其中，不再有步骤脚本或转发壳。ComfyUI 入口是并列的 `comfyui-tui.sh`，不是本词的扩展。
_Avoid_: 编排器、主控脚本、模块化脚本

**TUI（主菜单）**
启动即进入的交互界面：顶部实时状态行 + 固定编号功能项 + `q` 退出。启动只做环境前置检查与状态探测，不安装软件、不初始化系统、不写文件。
_Avoid_: 向导、配置中心、UI 框架

**原生状态**
判断系统现状的唯一依据：`sshd -T`、`ss -tln`、`ufw status`/`ufw show added`、`~/.ssh/authorized_keys`、`passwd -S`、`sudo -l -U`、`fail2ban-client status sshd`、`/etc/fail2ban/jail.local`、`/proc/swaps`、`/etc/fstab`、`sysctl`、`20auto-upgrades`、`dpkg-query`。项目**不保存**任何自己的状态文件。
_Avoid_: 缓存状态、配置快照、进度文件

**标准初始化**（菜单 `0`）
按固定顺序引导全流程的动作：环境概览与 Snapshot 确认 → 系统更新与基础工具 → 时区/NTP 检查 → 管理员与密钥 → UFW/SSH 加固 → fail2ban → Swap → BBR → 自动更新复核/终检。每一步先读原生状态，只修改未达标项；任何安全检查失败或确认拒绝都立即中止剩余步骤。
_Avoid_: 一键脚本、全自动安装

**闸门**
脚本内强制的人工确认点（`[y/n]` 交互，大小写都认）。对应三条铁律的生死关口；答 N 即中止当前流程，不存在"跳过"。
_Avoid_: 确认弹窗、跳过选项

**前置自检**
动作开始前对系统真实状态的检查（ufw 是否放行端口、用户是否存在、sshd 端口是否可读）。不满足即拒绝该动作。检查的是当下系统状态，不是脚本自己的历史记录。
_Avoid_: 状态检查文件、进度记录

**动作隔离**（`act`）
菜单动作的执行约定：临时关闭 `errexit` 与 ERR trap，动作内每个危险步骤显式判错（`|| die_action` / `if !`），失败只中止该动作并打印原因，TUI 继续可用。与 `die` 的分工是：`die` 只用于启动前置检查与输入中断（进程已无法继续）。
_Avoid_: 错误吞掉、静默失败

**交互契约**
主菜单与子菜单共用的输入语义：主菜单 `0`–`9` 选功能、`q` 退出、**空输入原地重问**（不得映射成 `0`）；子菜单 `0` 或空回车返回主菜单；非法输入原地重问、不整页重绘；`Ctrl-C` 打印"可能只改了一半、重跑收敛"的说明后以退出码 130 退出。菜单编号与 `README.md`/`features.md` 的引用一一对应，改编号必须同批改文档。
_Avoid_: 菜单框架、UI 库

**清屏契约**
仅在 stdout 是 TTY 且 `TERM` 可用、非 `dumb` 时清屏（Bash 内置 ANSI 序列，不依赖 `dialog`/`whiptail`）：启动绘制菜单前、切换页面前、用户确认看完动作输出后。动作输出、错误诊断、双闸门提示在用户确认前不清屏。
_Avoid_: 全屏刷新、界面重绘

**输入中断**
交互提示处读到 EOF（`Ctrl-D` 或输入流结束）时的终止语义：进程立即以退出码 1 退出，绝不把空值写入系统配置。实现依赖 `shopt -s inherit_errexit`——bash 默认不把 errexit 继承进命令替换，不开启则 `$(ask_input ...)` 里的 `die` 只终止子 shell，空值会被照常写盘。
_Avoid_: 输入错误、参数非法

**备份目录**（`/root/vps-init-backups/<时间戳>/`）
写任何系统配置文件前自动留存的副本。只保留最近 `BK_KEEP`（默认 20）份，超出由 `bk_prune` 删最旧；内容与最新一份相同则复用该目录并刷新时间戳。裁剪只匹配 `YYYYmmdd-HHMMSS` 目录名，目录下的其他内容一律不碰。恢复靠人工（例外：菜单 5 的「从备份恢复」会先 `sshd -t`，失败即退回恢复前的版本）。
_Avoid_: 快照、版本库

**终检报告**（`/root/vps-init-report.md`）
菜单 `9` 产出的绿/红/黄检查报告，兼作当前状态归档。只由实时检查结果生成；含完整 ufw 规则列表供人工核对历史端口。有红项时该动作返回 1。
_Avoid_: 审计日志、状态缓存

**fail closed**
校验条件无法确认时选择**拒绝写入/拒绝执行**，而不是用默认值继续。应用点：菜单 6 读不到 sshd 端口、或 jail 端口与 sshd 不一致时拒绝写 `jail.local`；菜单 5 未放行目标端口时拒绝启用 ufw。相对地，只读检查中的不确定用黄灯（"未知"）表达，不判红也不假装通过。
_Avoid_: 兜底、降级放行

**原始执行（raw 执行）**
主交付形态：`sudo -i` 后在 root 会话里 `bash <(curl -fsSL <raw URL>)`，脚本不进磁盘、不预装 git。与「本地副本执行」只有脚本来源不同，行为完全一致。
_Avoid_: 在线版、云执行

**本地副本执行**
可选形态：`git clone` 仓库到 VPS 后 `bash 00-tui.sh`。用于整套固定版本、执行前审阅、反复进菜单。脚本自包含，因此执行目录不影响行为。
_Avoid_: Git 版、离线版（本地副本仍需要网络装包）

**CodeWiki**
`docs/codewiki/` 下的维护者知识库：业务边界、架构、功能清单、开发流程、术语。回答"为什么"与"怎么改"；`README.md` 回答"怎么用"。
_Avoid_: 文档站、知识库（泛称）
